# Calculo-Numerico-Trabalho-I
Neste trabalho, implemento métodos numéricos para achar raízes aproximadas para funções quaisquer.

Implemento uma classe para utilizar polinômios e suas derivadas em polinomio.py; Em bisseccao.py, newton.py e secantes.py implemento funções para realizar os métodos e gerar arquivos de texto de saída formatados como uma tabela; Em main.py, utilizo as funções e classe criadas para gerar os arquivos.
